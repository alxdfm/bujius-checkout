## Handoff A → B (after A5)

- `verifySplitPayment(connection, signature, config, amount, reference, expiresAt?)` is on `main`.
  **`expiresAt` is a `Date`** (not seconds, not milliseconds); `blockTime` after it → `paid_late`.
  Returns `{ status: 'paid' | 'paid_late' | 'invalid', reason?, legs }`.
- It works for both strategies and needs the same `config` (with `address`) that built the payment.
  The status route may now mark `paid` — only from this verdict, never from `findPayment` alone.
- The verifier calls `getParsedTransaction` at `confirmed`; an RPC failure throws `RPC_UNAVAILABLE`.
